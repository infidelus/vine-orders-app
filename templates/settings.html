Automatic Backups

When switched on, the app saves a copy of your database once a day, named by date (e.g. vine_orders-2026-11-19.db), and deletes the oldest copies once there are more than the number you choose to keep.

The full folder being used is shown under Backups below - start the folder with / for a full path, otherwise it's inside the app's own folder.

Choosing a backup folder

Leave it as backups to keep backups in a folder inside the app's own folder. Any full path can be used instead, as long as the app can write to it. The app creates the folder if it doesn't exist and tells you if it can't use it.

Running in Docker (e.g. on Unraid): the app can only see folders the container has been given. To back up somewhere else, such as a different share, edit the container and add a Path, for example container path /backups and host path /mnt/user/backups/vine-orders, then enter /backups here.

Picture Catch-up

Fills in pictures for orders that don't have one, by looking up each order's Amazon page in turn. To avoid bothering Amazon it goes slowly - one order at a time, with a pause between each - and waits if Amazon starts showing its "are you a robot?" page. It carries on in the background on the server, so you can close this page or your browser; come back any time to see how it's getting on.
